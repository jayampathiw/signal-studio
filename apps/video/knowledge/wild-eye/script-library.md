## HOW TO USE THIS FILE
 
This file gives Claude pattern-matching material on proven Wild Capture scripts.
When generating new scripts:
 
- Match the structural format of the examples below
- Match audio specificity — never vague, always concrete
- Match lighting language — always directional, always purposeful
- Match narration register — sparse, first-person, whispered weight
- For 11s reels: prioritise Hidden Intimacy formula (drives reach)
- For 21s reels: prioritise Tension/Survival formula (drives follows)
Performance tiers:
[HIGHEST PERFORMER] — proven top reel, benchmark everything against this
[STRONG] — positive distribution, good follow conversion
[BASELINE] — posted, neutral or slightly negative distribution
[HIGH WATCH-THROUGH / LOW REACH] — content quality high but hook failed
[NOT YET POSTED] — script written, not in data yet
 
---
 
## SCRIPT QUALITY BENCHMARKS
 
Before finalising any script, check against these standards:
 
| Element | Required standard |
|---|---|
| Audio | "Layered soft breathing of four animals slightly out of sync" — never "quiet sounds" |
| Lighting | Always directional and emotionally purposeful. "Warm amber shaft catching only the eye" — not "dim lighting" |
| Camera motion | Named and justified. "Near-imperceptible push-in building intimacy" — not "slow camera" |
| Narration | 1–2 lines max. Whispered. Present tense. Weight without description. |
| Action | Micro-events not macro-drama. "One pup's paw twitches and stills" — not "animals sleep peacefully" |
| Duration | Always specified in seconds per scene |
| Hook | First 2 seconds must stop the scroll. If watch-through is high but views are low, the opening frame failed. |
