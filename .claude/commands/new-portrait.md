# /new-portrait [concept]

Create a new Wild Capture image portrait brief and generate it via Higgsfield.

**Format:** portrait | 1 scene | Type: image only (no video) | Slot: Sun/Thu 10:00 BST
**Goal:** Engagement — comments, brand recognition. Low-risk day content.

**What makes a strong portrait:**

- Extreme close-up, single subject
- ONE dramatic light source — amber shaft, cool morning light, golden hour rim
- Photorealistic fur / whisker / eye detail
- Vertical framing (9:16)
- No text overlay

**Portrait description rules (different from Reels):**

- 2–3 sentences MAXIMUM
- Ends with a direct QUESTION (not "Follow for more..." — portraits use questions for comments)
- Fewer hashtags: exactly 6–8 (Facebook image algorithm is less hashtag-driven)

**Post at 10:00 — midday browsing performs better for images than evening.**

**Example briefs that work:**

- Sleeping pup macro — extreme close-up, single tiny paw extended, amber burrow light
- Alert ears at golden hour — side profile, both ears erect, individual hairs translucent at edges
- Burrow threshold — cavy face half-in/half-out of entrance, split warm/cool light

**Usage:**

- `/new-portrait` — prompts for a concept
- `/new-portrait Cavy face at the burrow threshold, half warm half cool light` — direct concept

Creates a `content_items` brief with `format='portrait'`, `slot='Sun/Thu 10:00 BST'`, then runs storyboard-first image generation via Higgsfield.
